A zero-dependency Node 22 program that draws a one-page front page of the world's news for Wednesday 18 November 2026 (the US-Iran fighting in the Gulf, Putin and Xi at APEC, the Quad in Manila, Ukraine talks, West Bank sanctions and Gaza, markets) with its own pixel font and vector icons, and writes it as a deterministic PNG.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
